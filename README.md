# ArtSell - Vercel + Supabase

This is the Caffeine-independent rebuild of the ArtSell e-commerce application.

Stack:
- Next.js
- Vercel
- Supabase PostgreSQL
- Supabase Storage
- Stripe Checkout

No Caffeine, ICP canisters, Motoko, Internet Identity, Prisma, or Vercel Blob are required.

See `DEPLOYMENT_SIMPLE.md` for the setup order and `supabase.sql` for the database setup.
